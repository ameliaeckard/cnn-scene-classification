# AI Usage Disclosure

I used ChatGPT as a code assist during this project.

## How AI Was Used

| Area | AI Assistance |
|---|---|
| Debugging | Helped interpret training output, identify possible overfitting, and reason about model performance. |
| Code assistance | Helped explain and revise portions of the training workflow when needed. |
| Results interpretation | Helped compare validation results across experiments and summarize what each experiment demonstrated. |

## How AI Was Not Used

AI was not used to generate or alter the experimental results reported in this project. All validation accuracies and training results came from running the models and experiments directly.
AI was not used in generating ideas.
I reviewed the generated suggestions, made the final implementation decisions, and verified the code and results myself.

## Example Uses

Some examples of questions I asked ChatGPT included:

- How could I change this code to have it work like xyz?
- What do these results mean in comparison to xyz?
- Why is this section of code not working as intended?

AI was used as a support tool rather than as a replacement for running, evaluating, or understanding the experiments.
